# UPAP — Universal Professions AI Platform
### نظام تشغيل المهن — منصة واحدة، كل المهن، كل الدول

---

## الرؤية

منصة واحدة تخدم كل المهن (محاماة، محاسبة، طب، هندسة...) في كل الدول (20 دولة
من اليوم الأول)، بكل اللغات العربية والغربية الرئيسية. كل مهنة لها واجهتها
الخاصة تلقائياً، لكن البنية التحتية (المحرك، الذاكرة، الامتثال، الأمان) موحّدة
بالكامل. الهدف: بيئة عمل متكاملة، وليست مجرد "أداة" يسهل تقليدها.

**الترتيب الجغرافي**: أمريكا وأوروبا أولاً → الخليج → العالم العربي → العالم.

## البنية المعمارية (7 طبقات)

| الطبقة | الوظيفة |
|---|---|
| `core/` | النواة: محرك AI (OpenRouter + Gemini fallback)، قاعدة البيانات، سجل المراجعة |
| `core/factory/` | مصنع الوكلاء: `createAgent()`، `registry`، قوالب جاهزة للنسخ |
| `professions/` | وحدة مستقلة لكل مهنة (فارغة الآن عدا القالب — تُملأ وكيلاً وكيلاً) |
| `ui/` | مكوّنات مشتركة + مولّد واجهات يتكيّف حسب المهنة تلقائياً |
| `compliance/` | قوانين كل دولة (20 دولة) + أنظمة الامتثال (GDPR, HIPAA, PDPL...) |
| `memory/` | الذاكرة التراكمية — كل طلب وتصحيح بشري يبني الخندق الدفاعي |
| `integrations/` | واتساب، بريد، Telegram، USDT/TRC20 للدفع |

## الإعداد (كل شيء مجاني بالكامل)

1. **OpenRouter** (المزود الأساسي): مفتاح مجاني من openrouter.ai — اختر موديلات `:free`.
2. **Google Gemini** (احتياطي): مفتاح مجاني من aistudio.google.com.
3. **Supabase**: مشروع مجاني من supabase.com. الصق `supabase/migrations/001_initial.sql` في SQL Editor ونفّذه.
4. انسخ `.env.example` إلى `.env.local` واملأ القيم.

## التشغيل من الجوال

**GitHub Codespaces (الأسهل):**
ارفع المشروع لمستودع GitHub → Code → Create codespace → `npm install && npm run dev`

**Termux:**
```
pkg install nodejs git
git clone <رابط-المستودع> && cd upap
npm install
npm run dev
```

## النشر المجاني

اربط المستودع بـ Vercel (مجاني) → أضف متغيرات `.env.local` في إعدادات
المشروع → Deploy. رابط دائم يعمل من أي مكان.

## حالة المشروع الحالية

✅ النواة (Core) جاهزة: محرك AI، قاعدة البيانات، سجل المراجعة، مصنع الوكلاء، الامتثال لـ 3 دول نموذجية (US, SA, SY)، 5 مكوّنات UI أساسية، مولّد الواجهات.

⏳ لم يُبنَ بعد: أي وكيل فعلي (كل ما هو موجود قوالب فارغة قابلة للنسخ)، أي واجهة نهائية لمهنة محددة.

**الخطوة التالية**: بناء أول وكيل فعلي — `accounting.invoice-reader` — بعد تأكيد صاحب المشروع. راجع `CLAUDE.md` لقواعد العمل الكاملة.
